# Single-site configuration examples

Home for sanitized, versioned configuration examples and schemas once consumers
exist. One installation has one site configuration, which may describe many pumps,
chillers, rooms, loops, and sensors. Do not create a tenant or customer-site registry.

Expected concerns include equipment topology references, sensor mappings, units,
operating parameters, simulator settings, forecast history/fallback configuration,
model references, and pilot simulation limits. CAD-derived geometry does not replace
validated equipment specifications and operating parameters.

Keep actual host addresses, credentials, customer configuration, and generated site
artifacts in ignored `.local/`, `var/`, or installation-managed external storage.
No configuration format or fictitious equipment values are selected yet.
